SIDE QUEST · MOVING DAY

Bring your progress.

The game has a new address. Your old character, unlocks and saved run may still be here on this device.

  1. Open this page in the same browser you played in. Used a Home Screen app? Reopen its existing icon instead.
  2. Download your backup below.
  3. At the new game, open Settings → Save backup / restore and choose that file.

    Can't find your save?

    Try the same device and browser you used before. Private browsing and clearing site data can remove saves.

    On iPhone, the old Home Screen app has its own storage. Keep that app installed. Close and reopen its existing icon to load this transfer page at the old game address. A new install or a Safari tab cannot read the old app's storage.

    Old browser bookmarks: festival edition · original edition. These links alone do not reopen an installed app.

    Downloads are usually in Files → Downloads on iPhone. If offered, use Save to Files / share to save the backup. Restore each edition from its own Settings screen.

    Installing the new game may start with an empty save even after a Safari import. Open the new installed app and import the same backup there. Check your character and progress before removing the old icon.

    Need a hand? Open a support issue. Please don't attach your save file publicly.
