    Can't find your save?

    Try the same device and browser you used before. Private browsing and clearing site data can remove saves.

    On iPhone, an installed Home Screen app may have separate storage from Safari. Keep the old app installed. If it still opens, use its Settings backup option if available. This page cannot reach another browser or app's storage.

    Downloads are usually in Files → Downloads on iPhone. Restore each edition from its own Settings screen. Install the new game only after checking your progress there.
